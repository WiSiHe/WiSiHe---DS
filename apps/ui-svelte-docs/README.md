# ui-svelte-docs

Storybook app for `@wisihe/ui-svelte`.

## Scripts

- `pnpm --filter ui-svelte-docs storybook` - Run Storybook locally on port `6007`
- `pnpm --filter ui-svelte-docs build-storybook` - Build static Storybook output
- `pnpm --filter ui-svelte-docs lint` - Lint TypeScript config and stories
